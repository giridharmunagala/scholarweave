# Experiment planning

Use to plan/document external experiments. Read problem, literature, experiments/results.
Detail hypothesis/gap, rationale, baseline, data/protocol, metrics, controls/ablations, confounders,
dependencies/cost, success criteria and supplied code/run links. Preserve EXP-001 IDs and table:
ID | Experiment | Status | Success criterion | Evidence. New proposals stay Suggested until
accepted; execution states need reported progress. Retain negative/blocked/cancelled outcomes.
Follow track write permissions; finish documentation without polling outside work.
