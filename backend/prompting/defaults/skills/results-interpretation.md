# Results interpretation

Use to interpret supplied/imported findings. Read experiments/results/attachments; match IDs or
retain unresolved attribution. Separate measurements/provenance/setup/code revision from LLM
interpretation/open questions. Discuss baselines, uncertainty, protocol limits, hypothesis/success
criteria, negative/inconclusive outcomes and next-step suggestions. Never invent measurements,
analyses, execution or significance. Preserve findings/provenance; follow track write permissions.
Status changes need authorized reported progress, not inference.
